# FOLIO V6 — 사이트 안에서 캐릭터 편집 + Pages CMS 공개 반영

이번 버전은 기존 우측 상단 캐릭터 목록, 미니멀 도감, 영우(影偶)의 200×200 YouTube 테마곡을 유지합니다.

## 바로 사용하기

1. `FOLIO_Editor_v6_preview.html` 파일을 다운로드해 Chrome 등 브라우저에서 여세요.
2. 오른쪽 위 **EDIT**를 누르세요. 휴대폰에서는 헤더의 **EDIT** 버튼을 누르세요.
3. 왼쪽에서 영우·주진윤·담포영을 선택하거나 `＋ 캐릭터 추가`를 누르세요.
4. 프로필/대사/세계관/유튜브 링크를 수정하고 **브라우저에 저장**을 누르세요.
5. **저장하고 프로필 보기**를 누르면 수정된 내용을 바로 확인할 수 있어요.

### 이번 버전 편집 기능

- 캐릭터 새로 만들기, 내용 수정하기, 로컬 편집본 삭제하기
- 이름, 나이, 소속, 직업, 세계관, 대표 대사, 이야기, 관계 식별자, 공개 여부, 정렬 순서
- 대표 일러스트 URL/파일 경로 또는 **내 컴퓨터 이미지 업로드**(미리보기용 자동 축소)
- 갤러리 이미지 주소 등록, 유튜브 테마곡 주소 변경(영우의 囍 포함)
- 첫 화면 제목/소개/대표 캐릭터/About/하단 문구 수정
- JSON 백업 다운로드 및 다시 불러오기, 브라우저 내 편집 초기화

### 중요한 차이: 두 가지 저장 방식

| | 브라우저 EDIT | Pages CMS (로그인 필요) |
|---|---|---|
| 어디서 사용? | 내 홈페이지의 EDIT 메뉴 | https://app.pagescms.org |
| 로그인? | 없음 | GitHub 계정 필요 |
| 수정 결과 | 현재 브라우저에서만 보임 | 공개 홈페이지에 반영됨 |
| 이미지/음악 파일 업로드 | 대표 이미지의 브라우저 미리보기만 | GitHub 저장소에 실제 업로드 가능 |
| 다른 방문자에게 보여? | 아니요 | 배포 후 예 |

- **EDIT는 암호 없는 개인 미리보기 기능**입니다. 다른 방문자도 버튼을 볼 수 있지만 각자 자신의 브라우저 저장본만 바꿀 수 있고, 공개 사이트를 덮어쓸 수 없습니다. 비밀번호/로그인을 구현한 관리자 화면처럼 취급하지 마세요.
- 브라우저 내 저장은 `localStorage`이므로 기기나 브라우저가 바뀌거나 캐시/사이트 데이터가 삭제되면 편집본이 사라집니다. **JSON 백업을 내려받아 보관**하세요.
- 별도 HTML 파일로 로컬에서 열었을 경우 브라우저 보안/설정에 따라 저장 기능이 제한될 수 있습니다. 이 경우 GitHub Pages HTTPS 주소를 이용하세요.
- 브라우저 업로드 이미지는 브라우저에서만 사용됩니다. JSON 백업에 포함된 data URL은 Pages CMS로 자동 업로드되는 파일이 아닙니다. **온라인에 게시하려면 Pages CMS에서 원본 이미지를 올려야 합니다.**
- `공개 여부`를 꺼도 GitHub 공개 저장소에 원본 JSON을 업로드했다면 다른 사람이 원본을 볼 수 있습니다. 진짜 비밀 설정이나 저작권상 공개할 수 없는 파일은 넣지 마세요.
- **사이트 안에서 저장만 눌러 공개 홈페이지를 직접 수정하는 기능은 없습니다.** GitHub Pages는 정적 사이트이고 인증이 필요하기 때문입니다. 실제 공개 편집은 Pages CMS를 사용하세요.

## 공개 홈페이지로 배포하기

1. ZIP 안의 파일 **전부**를 GitHub 저장소 루트에 업로드하세요(기존 프로젝트 업데이트라면 덮어쓰기). `.pages.yml`과 `.github` 숨김 파일도 필요합니다.
2. GitHub 저장소 `Settings → Pages`에서 소스를 `GitHub Actions`로 선택하세요.
3. Actions 실행이 완료되면 GitHub Pages 주소에서 확인하세요.
4. `https://app.pagescms.org`에서 GitHub 로그인, FOLIO 저장소 선택 → **캐릭터 관리** 또는 **홈페이지 문구·대표 캐릭터**에서 편집 후 저장하면 자동 배포됩니다.

**유튜브 음악:** 영우 프로필 이름 옆 200×200 크기, 진입 시 자동재생 시도. 소리 있는 자동재생은 브라우저에서 차단될 수 있습니다. `file://` 미리보기에서는 유튜브 오류 153 방지를 위해 영상 원본 링크를 표시합니다. 실제 HTTPS 게시 사이트에서는 공식 임베드를 사용합니다.

## 프로젝트 파일

- `index.html`, `styles.css`, `app.js` — 사용자 홈페이지
- `editor.js` — 브라우저 편집·이미지 축소·JSON 백업 기능
- `.pages.yml` — GitHub 기반 편집 Pages CMS 설정
- `content/characters/*.json` — 캐릭터별 공개용 데이터
- `content/site.json` — 홈페이지 문구
- `assets/images/`, `assets/audio/` — 이미지/음악
- `scripts/build.mjs` — 사이트 재생성, `npm run build`
- `.github/workflows/deploy.yml` — CMS 저장 후 GitHub Pages 자동 배포
- `dist/` — 미리 생성된 게시용 정적 사이트

## 새 캐릭터를 Pages CMS에 등록할 때

필수 `id`는 소문자 영문·숫자·하이픈을 쓰세요. 예: `hayeon`. `name`, `published` 등 필드를 입력하고 저장하면 됩니다. 실제 새로 등록한 캐릭터가 새 페이지에 등장하려면 배포가 성공해야 합니다.
